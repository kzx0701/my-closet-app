# MyCloset 设计规范

> 本文档是 MyCloset（我的家庭衣橱）项目的整体设计规范，覆盖风格定位、配色体系、字体策略、布局原则、组件规范和注意事项。所有页面设计均以本文档为准。

---

## 一、风格定位

### 美学方向

**Refined Minimalism（精致极简）× Organic Natural（有机自然）**

参考 MUJI 的克制、Kinfolk 的温度、独立生活杂志的排印质感。追求"有性格的好看"而非"安全的中庸"。每个页面都应有清晰的视觉焦点和记忆点，不做没有意图的填充。

### 设计原则

1. **克制优先**：少即是多。不堆砌卡片、不加多余装饰线、不滥用阴影。高级感来自留白和精度，不是元素数量。一个细节做到 120 分，其他做到 80 分。
2. **内容即设计**：数据本身就是最好的视觉元素。数字、状态信息应直接参与构图，而非被塞进按钮或卡片里。操作入口和内容信息融合，不做"跳转按钮"。
3. **编辑排印感**：参考杂志排版——大字号衬线标题、等宽小字标签、分隔点连接的元信息行、左侧竖线引语。避免千篇一律的"卡片网格"。
4. **一体感**：页面背景和内容不应割裂。顶部状态区应与背景自然融合（渐变过渡），而非用独立卡片框死。

## 二、配色体系

### 主色调

| 角色 | 色值 | 用途 |
|------|------|------|
| 森林绿（主色） | `#3a5443` | 品牌主色，深色卡片背景，主操作按钮，强调文字 |
| 森林绿深 | `#2d4334` | 渐变起点，状态栏背景，深色文字（在浅色背景上） |
| 森林绿浅 | `#4a6755` | 深色卡片 hover 态 |
| 鼠尾草绿 | `#7a9580` | 渐变中间过渡色 |
| 鼠尾草浅 | `#a8bcae` | 渐变过渡色，深色卡片上的装饰文字 |

### 背景色

| 角色 | 色值 | 用途 |
|------|------|------|
| 燕麦色（页面底色） | `#f4efe6` | 页面主背景，温暖有纸张感 |
| 燕麦暖白 | `#f8f4ec` | 卡片背景，比页面底色略亮 |
| 燕麦深 | `#ebe4d6` | 次级背景，按钮 hover 态，分割线底色 |

### 强调色

| 角色 | 色值 | 用途 |
|------|------|------|
| 赤陶橙 | `#b85c3a` | 点缀色。用于关键数字（衣物数）、角色标签、季节竖线、斜体强调 |
| 赤陶浅 | `#d4805f` | 深色背景上的赤陶橙变体 |

**赤陶橙使用原则**：克制点缀，不大面积使用。每个页面最多 2-3 处，用于最需要吸睛的位置。和森林绿形成有高级感的色彩张力。

### 文字色

| 角色 | 色值 | 场景 |
|------|------|------|
| 深墨（主文字） | `#2a2a24` | 正文、标题，在浅色背景上使用 |
| 墨灰（次级文字） | `#4a4a42` | 标签、副标题、元信息值 |
| 中灰（辅助文字） | `#8a8a7e` | 描述文字、placeholder、mono 标签 |
| 暖白（反色文字） | `#f8f4ec` | 在森林绿背景上使用 |

**深色背景上的文字透明度规范**：
- 主文字：`rgba(244, 239, 230, 0.85)`
- 次级文字：`rgba(244, 239, 230, 0.5)`
- 辅助文字：`rgba(244, 239, 230, 0.35)`

### 边框与分割线

| 角色 | 色值 |
|------|------|
| 常规边框 | `rgba(58, 84, 67, 0.10)` |
| 轻分割线 | `rgba(58, 84, 67, 0.05)` |
| 深色背景上的分割线 | `rgba(244, 239, 230, 0.12)` |

### 季节动态色

页面顶部渐变光晕随季节微调色相，不改变整体色调：

| 季节 | 光晕色相 | 月份 |
|------|---------|------|
| 春 | 嫩芽绿 `rgba(168, 188, 174, 0.12)` | 3-5 |
| 夏 | 鼠尾草绿 `rgba(122, 149, 128, 0.12)` | 6-8 |
| 秋 | 赤陶暖 `rgba(184, 92, 58, 0.12)` | 9-11 |
| 冬 | 暖棕 `rgba(139, 111, 71, 0.12)` | 12-2 |

## 三、字体策略

### 字体家族

| 角色 | 字体 | 用途 | 小程序回退 |
|------|------|------|-----------|
| 展示字（Serif） | Fraunces | 大标题、数字、引语 | Songti SC / STSong / Georgia |
| 正文（Sans） | Manrope | 正文、描述、按钮文字 | PingFang SC / -apple-system |
| 标签（Mono） | JetBrains Mono | 元信息标签、编号、状态徽章 | SF Mono / Consolas |

### 字号阶梯

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Hero 标题 | 34px | 400（Regular） | 页面主标题（如"个人空间"），关键词用斜体 300 |
| 大数字 | 36-44px | 300（Light） | 统计数字、卡片数字，衬线体 |
| 区块标题 | 16-17px | 600（SemiBold） | 卡片标题、列表项标题，衬线体 |
| 正文 | 13-15px | 400（Regular） | 描述文字、正文段落 |
| 元信息值 | 14px | 500（Medium） | 元信息行的值，衬线体 |
| 标签 | 10-11px | 500-600 | mono 标签、统计标签，全大写 |
| 极小标签 | 9px | 400 | mono 极小标签，全大写，letter-spacing 1.5-2px |

### 字重使用原则

- **Light（300）**：大数字，营造纤细优雅感
- **Regular（400）**：正文、Hero 标题
- **Medium（500）**：元信息值、导航文字
- **SemiBold（600）**：卡片标题、区块标题
- **Bold（700+）**：慎用，仅用于极少数需要强调的场景

### 斜体使用

斜体（Italic）用于**关键词强调**，而非整段。在 Hero 标题中，关键词用斜体 + 更轻字重（300）+ 不同色相（如鼠尾草浅 / 赤陶浅），制造视觉层次。

## 四、布局原则

### 页面结构

页面采用**纵向滚动流**，自上而下按信息优先级排列。不使用横向网格分栏（移动端）。

### 留白节奏

- 页面左右边距：28px
- 区块间距：28-36px
- 卡片内边距：18-22px
- 元素间小间距：8-12px

留白应"大气而非均匀"——关键区域留白更大，次要区域紧凑，形成呼吸节奏。

### 背景与融合

**顶部状态区与背景融合**是核心设计语言。页面背景使用从深森林绿到燕麦色的**纵向渐变**，绿色集中在顶部约 40% 区域，42% 处完全过渡到燕麦色。状态信息直接"长"在绿色背景上，不用独立卡片框死。

渐变背景必须**随页面滚动**，不能固定不动。实现方式：在滚动容器内放置一个 `min-height: 100%` 的背景层，渐变和纹理叠加其上。

### 噪点纹理

全页叠加极淡的 SVG 噪点纹理（`opacity: 0.035`），模拟纸张质感，避免纯色背景的"塑料感"。纹理层不阻挡交互。

### 对比度要求

深色文字只能出现在燕麦色及更浅的背景上。绿色过渡区（渐变 28%-42% 区间）只放浅色文字。确保所有文字在对应背景上有足够对比度。

## 五、组件规范

### 状态信息区

页面顶部的空间状态展示。**不用独立卡片**，直接在渐变背景上排版：

- 顶部一行 mono 标签 + 脉冲圆点（如 `Personal Space`）
- 大字号衬线标题（如"个人空间"），关键词斜体
- 一行描述文字
- 底部元信息行：用分隔点 `·` 连接的键值对（如 `Mode 个人模式 · Family 尚未加入`），键用 mono 小字，值用衬线字

**禁止**：用圆角胶囊按钮展示状态标签。状态信息应融入排版，像杂志页眉的元信息。

### 数据概览

横向排列的统计数字，用竖线分隔，**不用卡片边框**：

- 数字用衬线体大字号 Light 字重
- 主数字用深墨绿色，核心数字（如衣物数）用赤陶橙点缀
- 标签用小字 SemiBold，中灰色
- 项与项之间用 1px 竖线分隔，不用间距+边框

### 操作卡片

核心操作入口采用**不对称对角布局**，打破"图标→标题→描述"的竖向堆叠：

- 左上角：大字号数字（实时数据）+ 小号单位词
- 右上角：极淡线性图标（opacity 0.4）
- 左下角：标题 + 副标题
- 右下角：斜向箭头，hover 时位移+变亮
- 一深一浅两张卡片并排，形成节奏

深色卡片用森林绿底 + 浅色文字；浅色卡片用燕麦暖白底 + 深色文字。浅色卡片的数字用赤陶橙点缀。

### 家庭协作区

- **已加入家庭**：家庭名 + 角色标签 → 邀请码（大字号衬线 + 复制按钮）→ 成员头像横排
- **未加入家庭**：引导文案 + 创建/加入双按钮（主按钮深色，次按钮描边）

### 季节贴士

左侧 2px 赤陶橙竖线 + mono 小标签 + 衬线斜体引语。像杂志的编者按，不用卡片包裹。

### TabBar

固定在屏幕最底部，不随页面滚动。半透明毛玻璃背景（`backdrop-filter: blur(20px)`），线性图标 + 文字，选中态用森林绿。

### 图标

全部使用**手绘 SVG 线条图标**（stroke-width 1.5），不用 emoji、不用填充图标、不用图标库默认样式。图标 opacity 控制在 0.3-0.4 作为装饰，不抢内容戏。

### 按钮

| 类型 | 样式 |
|------|------|
| 主按钮 | 森林绿底 + 暖白文字，圆角 20px |
| 次按钮 | 透明底 + 森林绿文字 + 1px 边框，圆角 20px |
| 图标按钮 | 圆形，半透明背景 + 边框 |

按钮高度 40-44px，不用大圆角胶囊（999px），用 20px 圆角更克制。

## 六、动效规范

### 页面加载

一次 **well-orchestrated 的错峰淡入**：从上到下各区块依次 `fadeUp`（透明度 0→1 + translateY 14px→0），延迟从 0.1s 递增到 0.66s，缓动函数 `cubic-bezier(0.2, 0.8, 0.2, 1)`。

**禁止**散落的微交互——不要每个元素都独立动画，一次编排好的入场比满屏闪烁更有质感。

### 交互反馈

- 卡片 hover：`translateY(-3px)` + 阴影加深
- 箭头 hover：位移 + 透明度增加
- 按钮 hover：背景色微调
- 所有过渡使用 `0.2s-0.35s ease`

### 滚动

页面平滑滚动（`scroll-behavior: smooth`），隐藏滚动条（`::-webkit-scrollbar { display: none }`）。

## 七、禁止事项

### 反 AI Slop

以下是最容易出现的"AI 味"设计，**严格禁止**：

1. **禁止紫色渐变**——特别是白底紫渐变，是 AI 生成设计的最大特征
2. **禁止 emoji 当图标**——用 SVG 线条图标代替
3. **禁止圆角卡片 + 左彩色 border accent**——2020-2024 的烂大街组合
4. **禁止 Inter / Roboto / Arial / 系统默认字体做展示字**——用 Fraunces 等有性格的字体
5. **禁止每处都配装饰性 icon**——icon 只在有信息价值时使用
6. **禁止均匀网格堆砌卡片**——用不对称布局、留白、错落感
7. **禁止状态标签用圆角胶囊按钮**——融入排版，用元信息行
8. **禁止编造数据填充**——没有数据就留白或诚实 placeholder

### 其他禁止

- 禁止页面背景固定不动——背景必须随滚动
- 禁止深色文字出现在绿色过渡区——确保对比度
- 禁止 TabBar 随页面滚动——必须固定底部
- 禁止满屏阴影——阴影只用于悬浮态，非常态
- 禁止硬编码颜色值——统一用 CSS 变量 / SCSS 变量

## 八、uni.scss Token 映射

项目 `uni.scss` 中的设计 Token 应与本规范保持一致。当前 Token 体系需根据本规范更新以下值：

- `$color-primary` 从 `#314033` 调整为 `#3a5443`（灰度鼠尾草绿，更高级）
- `$color-bg-page` 从 `#f7f4ee` 调整为 `#f4efe6`（燕麦色，更暖）
- 新增 `$color-terra: #b85c3a`（赤陶橙点缀色）
- 新增 `$color-terra-soft: #d4805f`（赤陶浅）
- 新增 `$color-sage: #7a9580`（鼠尾草绿）
- 新增 `$color-sage-light: #a8bcae`（鼠尾草浅）

字体变量需在页面级引入 Google Fonts（H5 端），小程序端回退到系统衬线/无衬线字体。

## 九、页面设计优先级

按用户使用路径分批设计，每批完成后对照本规范验收：

| 批次 | 页面 | 状态 |
|------|------|------|
| 第一批 | 首页、衣橱列表、衣物列表 | 首页已定稿 |
| 第二批 | 新建衣橱、新增衣物、衣物详情 | 待设计 |
| 第三批 | 登录、注册、启动页、家庭引导、创建家庭 | 待设计 |
| 第四批 | 个人中心 | 待设计 |

每个页面设计完成后，需确认：
- [ ] 配色符合本规范（无硬编码、无禁用色）
- [ ] 字体使用正确（衬线展示 + 无衬线正文 + mono 标签）
- [ ] 布局有不对称/留白/层次感（非均匀网格）
- [ ] 无 AI slop 特征（对照禁止清单逐项检查）
- [ ] 背景随滚动、文字对比度达标
- [ ] 动效为一次编排入场，非散落微交互
