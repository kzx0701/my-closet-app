# 首页排版修复计划

## 概述

修复 `pages/home/index.vue` 与设计稿 `docs/home-design-v4.html` 的排版差异。核心需求：
1. 顶部标题（个人空间/温馨一家）整个标题统一斜体，不再拆分成"正常+斜体"两部分
2. 修复对比中发现的隐性排版 bug（display: block 缺失导致 margin/max-width/transform 失效）

## 当前问题分析

### 核心问题：标题拆分

当前标题被拆成两部分：
- template：`{{ scopeTitleMain }}<text class="scope-title-em">{{ scopeTitleSub }}</text>`
- 个人模式："个人"正常 + "空间"斜体
- 家庭模式：家庭名首字正常 + 剩余字斜体

用户要求：整个标题统一斜体风格，不拆分。

### 隐性 bug：display: block 缺失

对比中发现 3 处 `<text>` 元素缺少 `display: block`，导致：
- `.scope-title`：`margin-bottom: 10px` 无效，`transform: skewX` 无法生效
- `.scope-desc`：`max-width: 280px` 无效，文本不会换行
- `.season-tip-text`：`transform: skewX` 无效，斜体实际未渲染

## 修改方案

所有修改仅涉及 `pages/home/index.vue` 单文件，`uni.scss` 无需改动。

### 修改 1：scope-title 统一斜体

**template（第 23-25 行）**

修改前：
```html
<text class="scope-title">
  {{ scopeTitleMain }}<text class="scope-title-em">{{ scopeTitleSub }}</text>
</text>
```

修改后：
```html
<text class="scope-title">{{ scopeTitle }}</text>
```

**script（第 246-255 行）**

将 `scopeTitleMain` 和 `scopeTitleSub` 合并为 `scopeTitle`：
```js
const scopeTitle = computed(() => {
  if (isFamilyMode.value) {
    return familyRecord.value?.name || "温馨一家";
  }
  return "个人空间";
});
```

**style（第 551-567 行）**

- `.scope-title` 新增 `display: block` + `transform: skewX(-8deg)` + `transform-origin: left center`
- 删除 `.scope-title-em` 规则
- 颜色统一为 `$color-text-inverse`，字重保持 400

### 修改 2：family-empty-title 统一斜体

**template（第 121 行）**

修改前：`<text class="family-empty-title">开启<text class="family-empty-em">家庭</text>协作</text>`

修改后：`<text class="family-empty-title">开启家庭协作</text>`

**style（第 964-978 行）**

- `.family-empty-title` 新增 `transform: skewX(-8deg)` + `transform-origin: center center`（居中锚点，因为父容器 text-align: center）
- 删除 `.family-empty-em` 规则
- 颜色统一为 `$color-primary-dark`

### 修改 3：scope-desc 补 display: block

**style（第 569-576 行）**

新增 `display: block`，修复 `max-width: 280px` 和 `margin-bottom: 20px` 失效问题。

### 修改 4：season-tip-text 补 display: block + 统一角度

**style（第 1052-1060 行）**

- 新增 `display: block`，修复 `transform: skewX` 失效问题
- `skewX(-6deg)` 改为 `skewX(-8deg)`，与其他斜体元素统一

### 修改 5（次要）：scope-meta-item 改 inline-flex

**style（第 585-589 行）**

`display: flex` 改为 `display: inline-flex`，对齐设计稿。

## 设计决策

| 决策 | 理由 |
|------|------|
| 用 `transform: skewX()` 而非 `font-style: italic` | iOS 微信小程序 italic 会导致中文字体 fallback 到楷体 |
| 标题颜色统一，不保留双色强调 | "不拆分"的必然结果，原 em 的 sage-light/terra 强调色不再适用 |
| `.scope-title` 用 `transform-origin: left center` | 标题左对齐，以左边缘为锚点倾斜 |
| `.family-empty-title` 用 `transform-origin: center center` | 父容器居中，以中心为锚点倾斜视觉更协调 |
| 家庭名 fallback 改为"温馨一家" | 对齐设计稿，原"家空间"不自然 |
| skewX 统一为 -8deg | 保持所有斜体元素角度一致 |
